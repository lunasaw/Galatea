# Delivery evidence

Include Campaign/request revision, project and dataset identities, Release/configuration/seed, authoritative run and candidate IDs, objective and final-test metrics, gate results, artifact references with digest and size, environment identity, load or inference contract, known limitations, and the platform report reference.

Use `accepted` only for a verified passed final test and complete integrity. Use `best-effort` only when the verifier returns that outcome and artifacts remain deliverable. Otherwise use `blocked`. Promotion requires a separate explicit platform action and is unsupported by this bundle.
