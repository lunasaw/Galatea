# Galatea Agent Docs

This directory documents the current SDK foundation for Galatea agents. Business-agent
execution docs should be added in the next phase when corresponding MCP tools exist.

## Current Docs

| Document | Purpose |
| --- | --- |
| `current-agent-architecture.md` | Current SDK foundation and active tool surface. |
| `python-agent-architecture.md` | Python package layout and SDK mapping. |
| `claude-sdk-development-guidelines.md` | Rules for SDK-native implementation. |
| `stage-contracts-and-tools.md` | Stage CLI status and next-phase tool contracts. |
| `configuration.md` | Runtime configuration and API environment. |
| `logging.md` | Request/response and audit logging guidance. |
| `implementation-roadmap.md` | Foundation status and next-phase business integration plan. |

## Documentation Rules

- Mark unimplemented business tools as planned.
- Do not document planned actions as current capabilities.
- Keep SDK base concerns separate from business-stage execution.
- Prefer exact MCP tool names and explicit permission behavior.
