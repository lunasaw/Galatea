# Model Strategy

Read [references/selection.md](references/selection.md). Inspect registered project, Campaign, Releases, configurations, and capabilities with tools from [the frozen contract](../../contracts/tools.json). Choose only IDs supplied and authorized by the platform.

Prefer a simple credible baseline that exercises the production architecture, then justify a bounded candidate method from task fit, resources, recovery support, evidence needs, and declared budget. State uncertainty. Do not invent configurations, dynamically build unregistered code, upload data, or turn unsupported LoRA/promotion work into an allowed path.
