# Galatea README Title Design

## Goal

Replace the generic README title `AI 训练一体化平台` with a memorable title that connects the
Galatea name to the platform's purpose.

## Approved title

`Galatea：让模型从数据中苏醒`

The title draws on the Galatea myth: something deliberately shaped is brought to life. In this
repository, data, code, configuration, and training infrastructure shape a model into a reproducible,
auditable, and recoverable training asset.

## Scope

- Change only the README level-one heading.
- Keep the existing one-sentence positioning statement and the rest of the README unchanged.
- Preserve all unrelated working-tree changes.

## Acceptance criteria

- The first README heading is exactly `# Galatea：让模型从数据中苏醒`.
- The existing platform positioning remains directly below the heading.
- No unrelated README content changes are introduced.
