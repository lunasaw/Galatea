# Validation 双阶段机器盲参考与统计协议 v1

本文件在私有参考调用前编写，补充冻结的
[P3 核验协议](daily-topic-sft-validation-protocol.md)，不改变原 200 条、分层或阈值。

## 证据展示与资格

参考模型逐条先读 selected 输入和真实 reply，再读已封存的同日、同会话过去前文。
两阶段分别请求并保存，第二阶段可看自己的首阶段结果，不看 GPT/Claude 的预审标签、分数、
分层、旧事实组或机器共识。缺失媒体和未给出的线下安排保持未知；扩展才出现的必要证据
不能使原输入变完整。所有索引回绑到原子消息 ID，原始响应仅保存于私有目录。

Gemini 合成路由失败时保留失败包；Opus 是独立模型和提示词的盲参考，但与 Claude 初审属于
同家族、使用同网关，因此仍可能有相关错误。四个合成例只检查路由与基本完整性判据，
不是参考审核器的真实数据准确率校准。模型返回名不是提供方权重 revision 证明。

## 统计公式

所有成功或失败项留在冻结总体，未核实计入分母；零分母或全部未知时 rate 和区间为 null。
报告 numerator、denominator、unknown、Wilson 95% 描述性区间。相邻 session 相关，
不把区间当总体覆盖率保证。两个阶段均满足才计支持，阶段间冲突不计支持。

| 指标 | 支持条件 | 分母 |
| --- | --- | --- |
| reply_link_support | 两阶段均 linked，候选原始回应锚点非空且全部被两阶段参考锚点支持 | 全部候选 |
| input_completeness_support | 两阶段均 sufficient；扩展专有必要证据必然不满足 | 全部候选 |
| machine_keep_support | 两阶段 linked/sufficient/useful/clear，且参考共同锚点与双初审共同锚点有交集 | 双初审共识 keep |
| erroneous_reject_support | 两阶段 linked/sufficient/useful/clear，且存在共同回应锚点 | 任一初审 reject 的非 keep 项 |
| uncertain_usable_support | 与上一行相同 | 双初审完成且无 reject 的非共识 keep 项 |

缺阶段、未知轴按指标记 unknown；明确不满足的轴记不支持。两者都不能算成功。
关联、完整性、机器 keep 支持率阈值分别为 98%、95%、95%，总体与关键层分别报告。
普通/短回复/引用/交错/低置信度各至少 20；其他层只诊断。keep 分母为零时不可估计。
补充报告保留/排除/延期与参考可用性的交叉表、阶段变更、遗漏证据和问题类型。

这些数值一律称机器审计支持率，不声称人工 precision。数值达标也不自动授予正式资格。
最终报告连接原始响应可重放的机器判断、盲参考和独立近重复审计，明确继续或返工。

## 执行与预算

每个模型先做最多 8 次纯合成请求。私有批次最多 400 首轮和 20 次单次失败修复，
4 并发，单次输出 2,000 token、120 秒；输入预留上限 8,000,000，输出预留上限 840,000。
每次输入预留为本地估算的 3 倍加 1,024，留 20,000 余量，不释放未用预留。
实报超过预留、身份漂移或连续路由故障触发停发；预留不是服务方账单上界保证。
已预留但无响应的请求不自动重发；有效判断不重问，封存重放不联网。

保持 training_run、人审完成、正式训练资格和 promotable 均为 false。
训练和服务发布仍依赖实施计划的后续门槛，盲参考不是训练 Run。

## 索引恢复补充（原盲参考封存后、恢复私有调用前冻结）

原 Opus 批次有 136 条双阶段有效参考。63 条首阶段的回应锚点指向 target 或越界，
另 1 条网络失败；这些不是合法参考标签。原始失败响应和已有效 136 条不改写。

新版本仅给剩余 64 条的输入附加由既有 speaker/index 计算的 self 索引允许列表，
强调回复作者是 target、不能把 target 自己的话当对方锚点；原文、候选 digest、过去证据、
语义判据和统计阈值均不改变，不自动将非法索引减一或改成最近 self。
先检查原四例和新增两例多轮角色交替合成案例，最多 12 次；私有恢复最多 128 首轮加 16 次
单次失败修复，输入预留 3,000,000、输出预留 288,000。已有效参考绝不为提高支持率重问。

最终合并报告注明参考请求存在两个输入注释版本，保留每条 request digest 和原始响应血缘。
这是响应契约失败恢复，不代表原版参考器已通过完整校准。
