## 当前状态

项目已具有数据与治理基础模块，但真实训练 Driver、正式评估、模型生成和应用检索接线仍待完成。
64 个现有测试通过表示组件/契约验证通过，不代表已经获得真实模型质量证据。
默认训练配置保持 blocked，本地聊天配置保持关闭。

## 维护方式

源码事实优先于历史设计。修改模块、入口、数据契约或运行边界时，同时更新方案文档、对应 JSON
图规格和来源索引。使用 archify 先 `validate` 再 `deliver`，随后对新的 HTML 执行
`visual-check` 并复核截图；不能只改 HTML 而保留旧的规格或回执。

原始需求、设计与运行手册仍保留在
