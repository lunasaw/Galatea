## 安全与验证边界

恢复机制不引入第二个模型循环，也不伪造 App 确认或治理授权。外部提交先按原幂等键对账，
unknown 不能重放。运行中的外部操作、核验、待用户决定、已排队回合、暂停/取消或绑定撤销
均阻止重复接续。新接口仅向绑定所属服务返回必要状态。

回归覆盖：确认后未 begin、begin 后未 prepare、prepare 后未提交、同回合幂等、Worker 重启、
无进展上限、实际进展重置、错误/中断回合、过期/撤销/跨会话绑定、控制与总预算、未知提交、
丢失 bind 回执、终态失败收尾、观察去重与状态回转、Host 状态持久化以及历史 App 恢复。
真实 Codex 0.163.0 + 本地模拟 Responses 验证实际协议、工具目录、两阶段产物核验和任务完成；
不调用真实模型、不执行训练。前端使用 TypeScript 检查及资源构建。

本机制只在回合结束后收敛任务；任意工具在单回合内反复调用仍需后续原生运行时层的
无进展检测。Goal 专用工具已从此部署移除，不能声称已解决所有可能的工具循环。
